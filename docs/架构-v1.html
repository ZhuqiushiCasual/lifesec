4.1 长期画像 ·「总结意识」

触发：
每日定时 / 新增 N 条事件 / 手动
处理：
扫描该用户全部事件 → LLM 压成一段精炼画像
形式：
单用户单行文本（参考 Hermes user.md）
慢变、低成本、全 context 注入

4.2 事实与统计

聚合 SQL：
本周运动次数
对比 SQL：
环比上周 / 上月
全量历史：
单用户数据量小，可直接取用
不过 LLM，实时查 —— 供「比较档」回应："这周第三次，比上周多"

4.3 洞察记忆

来源：
Hermes 推送
内容：
市场 / 行业 / 天气 / 行情（股票线后续抛弃）
作用：
外部变化 → 对当前计划的影响
外部驱动写入，不可自造
